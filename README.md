# BEST-KC — Kansas City Wedding Design & Boutique Florals

"The Cutting Room" — a scroll-driven 3D web experience built with React
Three Fiber, GSAP ScrollTrigger, and Tailwind CSS.

## Stack

- Vite + React + TypeScript
- React Three Fiber + drei (the Hero vitrine and Process-timeline callback)
- GSAP + ScrollTrigger (scroll-scrubbed camera and build sequence)
- Tailwind CSS v4

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
